# پوشهٔ رسانه

عکس‌ها و فیلم‌های گزارش‌ها که از پنل مدیر در برنامه افزوده می‌شوند، با نام‌هایی مانند
`k2x9ab1.jpg` در همین پوشه ذخیره و از طریق `raw.githubusercontent.com` نمایش داده می‌شوند.

- فرمت پیشنهادی عکس: JPG، حداکثر عرض ۹۰۰ پیکسل (برنامه خودش فشرده می‌کند)
- فرمت فیلم: MP4 (H.264) و صوت: MP3 — به‌صورت لینک اضافه می‌شوند
- به‌صورت دستی فایل‌ها را حذف نکنید مگر آن‌که گزارش مربوطه هم حذف شده باشد.
