## معرفی

«قرارگاه مردمی مدافعان وطن — محله کرمان» یک برنامهٔ سبک و کاملاً فارسی است برای اطلاع‌رسانی مراسمات و اخبار محله، نمایش گزارش‌های تصویری، دریافت نذورات و کمک‌ها، و ارتباط مردم با خادمان قرارگاه.

این برنامه در دو قالب ارائه می‌شود که محتوای مشترک دارند:

| قالب | فایل | توضیح |
|---|---|---|
| **اپ اندروید** | `android/` | اپ بومی Kotlin با WebView، اعلان‌های یادآوری، اجرای آفلاین |
| **برنامهٔ وب (PWA)** | `docs/` | روی هر گوشی و کامپیوتری در مرورگر باز می‌شود و قابل «افزودن به صفحهٔ اصلی» است |

ویژگی‌ها:

- 🕌 **مراسمات** با تقویم شمسی، شمارش معکوس، وضعیت «در حال برگزاری» و مسیریابی روی نقشه
- 📰 **اخبار** با نوار خبر متحرک در صفحهٔ اول
- 🖼️ **گزارش‌های تصویری** شامل عکس، فیلم و صوت با نمایش تمام‌صفحه
- 💝 **نذورات و کمک‌ها** با درگاه اینترنتی، شمارهٔ کارت و شبا (قابل کپی)
- 🤝 **فرم همکاری** و 💬 **انتقادات و پیشنهادات**
- 🌤️ **هوای تهران** به‌صورت آنلاین
- 🔔 **اعلان و یادآوری مراسمات** (در اپ اندروید)
- 🌙 حالت تیره/روشن، تنظیم اندازهٔ متن، و کارکرد **آفلاین**

## پنل مدیریت

برای ورود به پنل، **پنج بار روی شمارهٔ نسخه در پایین بخش «بیشتر» ضربه بزنید** و رمز را وارد کنید.

- رمز پیش‌فرض: `1234` — **حتماً** پس از اولین ورود، از پنل ← «تنظیمات» ← «رمز مدیر» آن را تغییر دهید.
- امکانات پنل: افزودن/ویرایش/حذف اخبار، مراسمات، گزارش‌ها، اعلان‌ها؛ تنظیم درگاه پرداخت و شمارهٔ کارت؛ عکس بنر صفحهٔ اول؛ وضع هوا؛ شمارهٔ تماس؛ نمایش/مخفی کردن بخش‌ها؛ صندوق پیام‌ها و فرم‌های همکاری.

## نصب روی گوشی (اندروید)

1. از بخش [Releases](https://github.com/husseinmilad/appmahalehkerman/releases/latest) فایل `qarargah-kerman-<نسخه>.apk` را دانلود کنید.
2. فایل را باز کنید؛ اگر پیام «برای امنیت، نصب برنامهٔ ناشناس مسدود شد» آمد، از همان پیام گزینهٔ «تنظیمات» ← «اجازه از این منبع» را فعال کنید.
3. نصب را تأیید کنید.
4. برای اعلان‌ها: بخش «بیشتر» ← «فعال‌سازی اعلان مراسمات» و اجازهٔ اعلان را بدهید.

> **iPhone:** نسخهٔ وب را در Safari باز کنید، دکمهٔ اشتراک‌گذاری ← «افزودن به صفحهٔ خانه».

│   │   ├── MainActivity.kt      # WebView + پل JavaScript
│   │   ├── Scheduler.kt         # زمان‌بندی یادآوری مراسمات
│   │   ├── NotificationWorker.kt

## راه‌اندازی نسخهٔ وب (GitHub Pages)

فقط یک بار لازم است:

1. **Settings** ← **Pages**
2. در بخش **Source** گزینهٔ **Deploy from a branch** را انتخاب کنید.
3. **Branch:** `main` و **Folder:** `/ (root)` را بگذارید و **Save** بزنید.
4. پس از حدود یک دقیقه:
   - صفحهٔ معرفی: `https://husseinmilad.github.io/appmahalehkerman/`
   - خود برنامه: `https://husseinmilad.github.io/appmahalehkerman/docs/`

> پوشهٔ `docs/` به این دلیل انتخاب شده که با گزینهٔ «Deploy from a branch» بدون نیاز به Workflow منتشر می‌شود.

## ساخت اپ اندروید با GitHub Actions

Workflow آماده است: `.github/workflows/android.yml`

- با هر **push** روی `main` یا اجرای دستی (Actions ← Android APK ← Run workflow) بیلد می‌شود.
- خروجی APK در بخش **Artifacts** همان اجرا و همچنین در صفحهٔ **Releases** با برچسب `v<نسخه>` منتشر می‌شود.
- برای انتشار نسخهٔ جدید، `android/version.properties` را تغییر دهید:

```properties
VERSION_NAME=1.0.1
VERSION_CODE=2
```

### امضای نسخهٔ انتشار (اختیاری)

بدون تنظیم Secrets، فایل `app-release.apk` با امضای debug ساخته می‌شود (برای تست و توزیع مستقیم کافی است). برای امضای رسمی، این Secretها را در **Settings ← Secrets and variables ← Actions** اضافه کنید:

| Secret | مقدار |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | خروجی `base64 -w0 release.jks` |
| `ANDROID_KEYSTORE_PASSWORD` | رمز فایل keystore |
| `ANDROID_KEY_ALIAS` | نام کلید |
| `ANDROID_KEY_PASSWORD` | رمز کلید |

ساخت keystore:

```bash
keytool -genkeypair -v -keystore release.jks -alias qarargah \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks > release.jks.b64
```

## ساخت دستی اپ اندروید

پیش‌نیازها: JDK 17، Android SDK (platform 35, build-tools 35.0.0)

```bash
cd android
./gradlew assembleDebug      # خروجی: app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # خروجی: app/build/outputs/apk/release/
```

آدرس نسخهٔ آنلاین را می‌توانید هنگام ساخت تغییر دهید:

```bash
./gradlew assembleDebug -PappUrl="https://example.com/"
```

> هنگام بیلد، `docs/index.html` به‌صورت خودکار داخل `assets/web/` کپی می‌شود؛ بنابراین اپ بدون اینترنت هم باز می‌شود.

## انتشار محتوا از پنل برنامه

محتوای عمومی (خبر، مراسم، گزارش، اعلان، تنظیمات پرداخت و…) در فایل `data/content.json` نگه‌داری می‌شود و عکس‌ها در پوشهٔ `media/`. مدیر از داخل برنامه این فایل را روی گیت‌هاب می‌نویسد و همهٔ کاربران آن را می‌خوانند.

مراحل اتصال (یک بار):

1. در گیت‌هاب: **Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token**
2. **Repository access:** فقط `appmahalehkerman`
3. **Permissions ← Repository permissions ← Contents:** `Read and write`
4. توکن ساخته‌شده را کپی کنید.
5. در برنامه: پنل مدیریت ← «تنظیمات» ← «اتصال به گیت‌هاب» ← توکن را بچسبانید ← «ذخیره و تست اتصال».

> 🔒 توکن فقط در حافظهٔ همان گوشی (localStorage) می‌ماند و به هیچ سروری جز `api.github.com` فرستاده نمی‌شود. آن را در اختیار دیگران نگذارید. برای ابطال، در گیت‌هاب توکن را Revoke کنید.

## حریم خصوصی و امنیت

- هیچ سرور واسطی وجود ندارد؛ همهٔ داده‌ها بین برنامه و `api.github.com` / `raw.githubusercontent.com` رد و بدل می‌شود.
- فرم‌های همکاری و پیام‌ها روی همان دستگاه ذخیره می‌شوند و در فایل محتوای عمومی منتشر **نمی‌شوند**.
- اپ اندروید فقط به دامنه‌های مورد نیاز (github.io، github.com، githubusercontent.com، open-meteo.com، googleapis.com) دسترسی دارد و ترافیک غیر HTTPS را مسدود می‌کند.
- اپ به مخاطبین، موقعیت مکانی، دوربین و حافظهٔ گوشی دسترسی ندارد.
